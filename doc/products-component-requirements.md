# 产品列表组件需求文档

## 目标
在 `app/components/products.tsx` 新建“产品列表”组件，视觉风格参考提供图片，支持不同宽度下的自适应布局。

## 组件范围
- 新增一个可复用的产品列表组件（建议命名 `Products`，以项目规范为准）。
- 仅要求前端展示层；数据获取与路由跳转行为由后续实现确认。

## 产品类型与行为
产品分两种类型，列表与卡片需支持区分展示与跳转逻辑：
1. **类型 A：详情页 + 下载**  
   - 示例：生日管理 app。  
   - 列表点击后进入二级详情页，页面包含产品介绍内容与“前往市场下载”的入口。  
2. **类型 B：直接在线 Demo**  
   - 示例：卡牌游戏。  
   - 列表点击后直接跳转到在线 Demo（外链或站内在线体验），不经过二级详情页。  

## 数据结构（展示字段）
单个产品项至少包含：
- `id`：唯一标识
- `title`：标题
- `cover`：封面图 URL
- `description`：简短介绍
附加字段（用于区分类型与跳转）：  
- `type`：产品类型（`detail` 或 `demo`）。  
- `detailUrl`：类型 A 的二级详情页地址。  
- `downloadUrl`：类型 A 的市场下载地址。  
- `demoUrl`：类型 B 的在线 Demo 地址。  

允许后续扩展字段（如价格、评分、促销信息等）。

## 布局与样式（参考图）
- **卡片结构**：封面图在上，文本信息在下。
- **封面图**：
  - 固定比例矩形（建议 16:9 或 4:3，最终由实现阶段确定）。
  - 圆角与轻阴影，营造轻浮层感。
- **文本区**：
  - 标题两行内截断。
  - 介绍文本一到两行截断。
- **列表布局**：
  - 卡片横向排列，间距一致。
  - 采用响应式网格换行布局。
- **视觉细节**：
  - 统一圆角、阴影、内边距。
  - 信息层级清晰，重点突出标题和封面图。

## 自适应与响应式
断点行为（已确认）：
- ≥1200px：5 列
- 992–1199px：4 列
- 768–991px：3 列
- 576–767px：2 列
- <576px：1 列

卡片宽度随容器变化，保持封面比例与文本间距一致。

## 交互与状态
- **悬停**：轻微上浮或阴影增强。
- **点击**：  
  - 单张卡片可点击。  
  - 类型 A：进入二级详情页（MD 页面）。  
  - 类型 B：直接跳转在线 Demo。  
- **空态**：无数据时显示统一占位或文案。
- **加载**：不需要 Loading/Skeleton，直接展示即可。

## 可访问性
- 图片需提供 `alt` 文本。
- 文字与背景对比度满足可读性要求。

## 限制与约束
- 仅新增组件，默认不修改其他文件。
- 视觉风格以参考图为主，结构与信息层级一致。

## 已确认事项
1. 列表采用响应式网格换行布局（非横向滚动）。
2. 断点与列数按建议执行。
3. 展示内容仅包含图片、标题、介绍。
4. 单张卡片可点击。
5. 二级详情页为 MD 页面。
6. 不需要 Loading/Skeleton 状态。
